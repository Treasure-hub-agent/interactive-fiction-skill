HOW IT PLAYS

一拍三式，永远不断线

普通 prompt 是「建议」，这里是「硬规则 + 每轮自检」。铁律 #0：正文之后必跟选项，正文结束不等于对话结束。

01

你说开头

一句话、一个念头
或直接「加载小说包」随机开局

02

它写一段

500–1200 字，视角、语态
与上一章严丝合缝

03

你选 A–E

五条分支互不重复
也可以自由输入言行

THE DIFFERENCE

别人的 AI vs 装上它之后

✕ 普通 prompt

雨夜。她站在窗后看着你，你推开门走了进去，你们交谈起来，气氛渐渐变得微妙，故事继续发展下去……

（正文结束，没有下文）

  • ✕写完就停，没有选项，剧情变成单向广播
  • ✕「你」和「他」混着用，视角漂移出戏
  • ✕战斗写 300 字，日常水 2000 字
  • ✕三条线一起开，后文互相矛盾
  • ✕断了就接不上，进度全靠自己记
✓ 装上 interactive-fiction

雨丝斜斜地切过灯笼的光……她似乎已经等你很久了。

  • ✓铁律 #0：每轮必跟 A–E 五选项
  • ✓视角硬规则，多角色切换有格式约束
  • ✓字数区间按场景分配，紧迫处不注水
  • ✓设定核对 · 伏笔回收 · 长线一致
  • ✓三档存档，断了能续，随时导出成书
