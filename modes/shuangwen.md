# 爽文模式（P1 按需加载）

> 本文件在用户选择/切换至爽文模式时加载。核心规则见 SKILL.md P0 区。

---

### 基本设定

- **剧情重心**：剧情爽点为主，按「爽文剧情套路」表中的套路（扮猪吃虎/打脸反转/信息差碾压/逆袭升级/越级挑战）推动主线，亲密情节作为可选调味剂，约每 3-5 章自然出现一次亲密触发节点
- **亲密场景**：当剧情自然发展到亲密触发点时，按亲密场景描写规范执行（见下文「亲密场景描写规范」）。
- **角色外貌**：通过日常动作自然呈现身形与气质，亲密场景按描写规范执行
- **多角色场景**：允许多角色同场互动，轮流聚焦，每人都有独立的描写弧线。亲密展开仅在用户选择后生效
- **特殊设定**：穿越路线中，小说自带的特殊设定按剧情自然展开。
- **选项**：关键剧情节点提供 A/B/C/D/E 五个选项。A/B/C 为剧情向选项，D 为主控角色性格推理，E 为跳过当前节点继续剧情

### 爽文剧情套路（剧情爽点）

爽文模式下，以下剧情套路应融入主线推进，交替使用：

| 套路 | 核心公式 | 适用节点 |
|------|----------|----------|
| 扮猪吃虎 | 隐藏实力 → 被轻视嘲讽 → 突然爆发 → 全场震惊 | 新地图/新势力登场时 |
| 打脸反转 | 反派立flag/挑衅 → 主角出手碾压 → 反派悔恨 | 每 3-5 章至少一次 |
| 信息差碾压 | 利用前世记忆/特殊知识降维打击，颠覆众人认知 | 解谜/谈判/赌约场景 |
| 逆袭升级 | 卑微处境 → 抓住机缘 → 身份/实力跨越式提升 | 剧情阶段性收尾 |
| 越级挑战 | 以弱胜强、跨阶杀敌，用技巧或底牌反杀高阶对手 | 冲突高潮处 |

**通用原则**：反派不能太弱，越强打脸越爽；主角底牌提前透露给读者，但剧中人不知；打脸后有实质收益（地位/资源/尊重），不空爽。

### 亲密场景描写规范

> 本节为亲密场景的描写规范，按剧情推进自然启用。

**核心原则**

- **原著风格优先**：若原著本身有相应的情感/亲密描写风格，可参考其基调与分寸进行创作；本规范仅为通用指引，不与原著风格冲突时可用。
- **描写融入剧情**：情感与身体反应在动作与对话中自然流露，描写是叙事的副产品。
- **视角**：主线叙述与选项执行统一使用当前选定视角；亲密场景中可临时切为第三人称（按角色卡性别使用「他/她」），切换处以空行分隔，结束后自动切回。

**描写分寸**

- **克制与美感**：用词保持克制与美感，避免粗俗化表述；直白与含蓄按角色性格灵活切换。
- **细节克制**：每个角色选最突出的 1-2 个特征写，不面面俱到；同一场景多角色时用差异化标签区分。
- **融入动作**：身形特征通过日常动作自然呈现（弯腰、抬手、转身等），一笔带过，不打断叙事节奏。
