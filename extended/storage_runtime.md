# 本地文件储存与运行时持久化（P2 按需加载）

> 本章在存档、切换小说、断连恢复、导出小说等存储操作触发时加载。包含本地文件储存系统与运行时状态持久化系统。

---

## 一、本地文件储存系统

> 存储根目录默认 `~/novels/`（可通过环境变量 `NOVEL_STORAGE_ROOT` 覆盖），下文以 `{存储根}` 指代，每部小说一个独立文件夹。

### 目录结构

```
{存储根}/
├── _index.json                         # 全局小说索引（含 global_characters 数组）
│
├── 通用角色卡/                          # 按作品分文件夹
│   └── characters/
│       ├── _roster.json
│       ├── 《示例作品A》/
│       │   ├── 示例角色A/  (profile.md, personality.md, ...)
│       │   └── 示例角色B/  ...
│       ├── 《示例作品B》/
│       │   └── 示例角色C/  ...
│       └── 自创/
│           └── 示例角色D/  ...
│
└── 《小说名》/
    ├── novel.json                       # 小说主配置
    │
    ├── worldbuilding/                   # 世界观设定
    │   ├── overview.md
    │   ├── era.md
    │   ├── power_system.md
    │   ├── geography.md
    │   ├── society.md
    │   ├── narrative_tone.md
    │   └── protagonist.md
    │
    ├── characters/                      # 角色卡
    │   ├── _roster.json
    │   ├── {slug}/                      # 蒸馏角色目录
    │   │   ├── SKILL.md
    │   │   ├── profile.md
    │   │   ├── personality.md
    │   │   ├── interaction.md
    │   │   ├── memory.md
    │   │   ├── relations.md
    │   │   └── manifest.json
    │   └── ...
    │
    ├── saves/                           # 存档（按路线隔离）
    │   ├── 穿越/
    │   │   ├── _meta.json
    │   │   └── 001.md
    │   ├── 自创/
    │   └── 创世/
    │
    ├── exports/                         # 导出小说文本
    │   └── {小说名}_【{路线}】_小说.txt
    │
    ├── meta/                            # 运行时元数据
    │   ├── relationships.json           # （已迁至 novel_runtime.json）
    │   ├── side_characters.json         # （已迁至 novel_runtime.json）
    │   └── plot_flags.json              # （已迁至 novel_runtime.json）
    │
    └── source/                          # 原著材料（可选）
```

### 核心设计原则

| 原则 | 说明 |
|------|------|
| **小说名即路径** | 直接用中文小说名建目录。_index.json 中维护映射 |
| **路线三级隔离** | 存档和导出按 穿越/自创/创世 分子目录，编号独立 |
| **蒸馏角色 vs 叙事角色** | 蒸馏角色落完整 skill 文件目录；叙事角色由 `novel_runtime.json` 权威托管 |
| **通用角色卡** | 独立于小说的角色卡池，存放于 `{存储根}/通用角色卡/characters/`。删除小说时默认将角色卡移至此目录保留复用；蒸馏/自创角色完成时可选择存入此目录 |
| **存档 Markdown 单文件** | 格式：`#存档 N` + `>摘要` + 正文 + `---状态摘要---` 区块 |
| **全局索引** | `_index.json` 记录所有小说的路径/路线/字数/更新时间 |

### 技能包指令 ↔ 存储操作映射

> 所有存储操作均由 AI 通过文件读写工具直接完成（读/写 JSON 与 Markdown 文件），无需任何外部 CLI。

| 技能包指令 | 对应存储操作 |
|-----------|-------------|
| 「存档」 | 写入持久存档文件 |
| 「查看存档」 | 列出 `{存储根}/{小说名}/saves/` 下所有存档 |
| 「加载XX路线存档」 | 读取对应路线的最新存档 |
| 「导出小说」 | 追加叙事正文到导出文件 |
| 「进度」 | 读取 `novel_runtime.json` 与存档元信息 |
| 「世界观」 | 读取世界观文件对应维度 |
| 「弹出XX角色卡」 | 读取 `characters/` 下对应角色卡 |
| 「小说管理」 | 扫描小说目录；删除时触发角色卡保护流程 |
| 「角色卡管理」 | 扫描通用角色卡库；删除需二次确认 |
| 「删除小说《XXX》」 | 删除小说目录；默认将角色卡移至 `通用角色卡/` |
| 「弹出XX的memory」 | 读取角色卡 memory 区块 |
| 「人物志」 | 列出所有已登场角色 |
| 「修改XX人设」 | 写入角色卡对应区块 |
| 「关系」 | 读取好感度数据 |
| 「配角动态」 | 读取配角后台活动数据 |
| 「切换路线」 | 重置存档编号，旧存档保留 |

## 二、运行时状态持久化系统

> **定位**：在持久存档之上，新增一层**每轮自动磁盘回写**的运行时状态持久化。依赖 AI 的文件读写能力（Write/Read 工具），无需外部 CLI。
>
> **核心文件**：`novel_runtime.json`（每轮更新） + `_index.json`（全局索引）

### 新增文件

| 文件 | 路径 | 创建时机 | 说明 |
|------|------|----------|------|
| 运行时状态 | `{存储根}/{小说名}/meta/novel_runtime.json` | 首次选择路线后 | 每轮更新，用于快速恢复 + 断连保护 |
| 全局索引 | `{存储根}/_index.json` | 首次创建小说时 | 记录所有小说 + 当前激活标记 |

> 首次使用时若 `{存储根}/` 或 `_index.json` 不存在，AI 自动创建目录与初始索引 `{"act":null,"nvs":[]}`。

### `_index.json` 格式

```json
{
  "act": "《示例小说A》",
  "nvs": [
    { "n":"《示例小说A》", "r":"穿越成原著角色", "u":"2026-01-01T12:00:00Z", "c":45230 },
    { "n":"《示例小说B》", "r":"自创角色",       "u":"2026-01-02T18:30:00Z", "c":18300 }
  ]
}
```

| 字段 | 含义 | 写入时机 |
|------|------|----------|
| `act` | 当前激活的小说名（`null`=无激活） | 创建/切换小说时 |
| `nvs[].n` | 小说名 | 创建时 |
| `nvs[].r` | 路线 | 创建/切换时 |
| `nvs[].u` | 最后更新时间 | 与 novel_runtime.json 同步写入 |
| `nvs[].c` | 累计字数 | 与 novel_runtime.json 同步写入 |

### `novel_runtime.json` 格式

```json
{
  "v":  "8.0",
  "ua": "2026-01-01T12:05:00Z",
  "nm": "《示例小说A》",
  "rn": "创世模式",
  "md": "爽文模式",
  "vw": 3,
  "ch": 5,
  "sc": "场景·示例地点",
  "wc": 32450,
  "mp": "区域·示例区域",
  "dv": null,
  "cc": "主角正在追查一条关键线索，牵动多方势力",
  "sb": ["支线地点一", "支线地点二"],
  "kp": ["关键决策一", "关键决策二"],
  "pf": [{"k":"伏笔一","s":"active"}, {"k":"伏笔二","s":"dropped"}],
  "rs": { "角色A":72, "角色B":45, "角色C":null },
  "cp": { "角色A": {"stage":"初识","progress":60}, "角色B":{"stage":"戒备","progress":25} },
  "scs": { "角色D":{"l":"A","a":3,"t":["后台事件一"]}, "角色E":{"l":"B","a":1,"t":[]} },
  "npcs": {},
  "choices": [
    { "seg":12, "picked":"B", "tag":"稳健周旋", "type":"关系", "detail":"示例势力对主角仍存轻视", "tier":"即时", "surface_by":14, "foreclosed":["A","C"] }
  ],
  "st": { "位置":"示例地点", "目标":"当前目标", "情绪":"警觉", "携带物品":["示例物品"] },
  "theme": null,
  "prv": "你在示例地点遇见了角色A。TA 无意中提起一条与主线相关的线索。",
  "ex": 2890,
  "eb": 0,
  "seg_count": 8,
    "ms": 7,
    "scs_bak": null
}
```

**字段速查**：

| 键 | 类型 | 含义 | 写入时机 |
|----|------|------|----------|
| `v` | string | 版本号 | 创建时固定 |
| `ua` | ISO8601 | 更新时间戳 | 每轮 |
| `nm` | string | 小说名 | 创建小说时固定 |
| `rn` | string | 当前路线 | 路线变更时 |
| `md` | string | 当前模式 | 模式切换时 |
| `vw` | int | 当前视角（1/2/3） | 视角切换时 |
| `ch` | int | 当前章数 | 推进时 |
| `sc` | string | 当前场景 | 场景切换时 |
| `wc` | int | 累计字数 | 每轮 |
| `mp` | string | 当前地图 | 场景切换时 |
| `dv` | int\|null | 原著偏离度（仅穿越路线） | 关键选择后 |
| `cc` | string\|null | 核心冲突（仅自创/创世） | 推进时 |
| `sb[]` | string[] | 未探索支线 | 场景切换时 |
| `kp[]` | string[] | 关键决策记录 | 关键选择后 |
| `pf[]` | array | 伏笔 `{k,s}` | 变化时 |
| `rs{}` | object | 角色好感度快照 | 变化时 |
| `cp{}` | object | 攻略进度快照 | 变化时 |
| `scs{}` | object | 配角后台 `{l,a,t}` | 后台活动生成时 |
| `npcs{}` | object | 配角角色卡 | 配角达标时 |
| `choices[]` | array | 选择后果账本（含 seg/picked/tag/type/detail/tier） | 选定 A/B/C 后 |
| `st{}` | object | 主角动态状态 `{位置,目标,情绪,携带物品}` | 状态变化时 |
| `theme` | string\|null | 主题锚点（null=纯爽文） | 开局配置时 |
| `prv` | string | 前情提要（≤200字） | 每轮 |
| `ex` | int | 导出游标 | 主线导出后 |
| `eb` | int | 缓冲区字节数 | 每轮 |
| `seg_count` | int | 正文段计数（驱动锚定钩子） | 每轮 |
| `ms` | int | 最近持久存档编号 | 手动存档后 |
| `scs_bak` | object\|null | 场景卡模式快照 | 进入场景卡时 |

### 写入策略

**核心原则**：novel_runtime.json 在每次叙事轮次结束后写入。

**写入触发表**：

| 触发事件 | 写入 novel_runtime.json | 同步 _index.json |
|----------|:--:|:--:|
| 每轮正文生成后（常规叙事） | ✅ 写入 | ❌ 不写 |
| 路线/模式/视角切换 | ✅ 写入 | ✅ 同步 |
| 关键选择 | ✅ 写入 | ❌ 不写 |
| 里程碑自动存档 | ✅ 写入 | ❌ 不写 |
| 导出小说 | ✅ 写入 | ❌ 不写 |
| 手动存档 | ✅ 写入 | ✅ 同步 |
| 场景/好感度/伏笔变化 | ✅ 合并到下次正文写入 | ❌ 不写 |
| 字数累加、`prv` 更新 | ✅ 合并到下次正文写入 | ❌ 不写 |
| 切换小说 | ✅ 写当前 → ✅ 写目标 | ✅ 写入 act |
| 场景卡模式中 | ❌ 不写入 | ❌ 不写 |
| 创建新书 | ✅ 首次写入 | ✅ 追加 nvs[] |
| 删除小说 | ❌ 不需写 | ✅ 移除 nvs[] |

> **合并写入**：标记为"合并到下次正文写入"的变化不触发独立写盘，而是在同一轮正文写入中一并完成。一轮正文只产生一次 novel_runtime.json 写入 + 一次 narrative_buffer.txt 追加。

**写入操作**：
- Write 工具写入 `{存储根}/{小说名}/meta/novel_runtime.json`
- 写入前校验：`prv` 字段若超过 200 字，自动截断至最后一个完整句子（≤200 字）
- 每轮正文生成后 `seg_count` 自增 1（并入本次正文回写，无独立 IO）；`seg_count` 为 8 的倍数时即触发锚定钩子重锚窗口（详见 SKILL.md 铁律#0 自检 + `extended/event_behaviors.md` §锚定钩子）
- 写入失败 → **不中断叙事**，继续使用上下文中的缓存状态，下轮重试

**读取时机**：
- 新对话（首次激活「加载小说包」）→ **不读取**，全新开始
- 断连恢复（用户输入「继续」）→ Read 工具读取 `novel_runtime.json`
- 切换小说 → Read 工具读取目标小说的 `novel_runtime.json`
- 常规轮次 → **不读取**（使用上下文中的缓存状态）

### 生命周期

**新对话（无历史上下文）**：
```
→ 用户首次发送激活指令（如「加载小说包」）
→ 此为全新开始，不自动读取任何磁盘状态
→ 展示路线选择，引导用户创建新冒险
```

**断连恢复（有历史上下文 + 时间间隔）**：
```
→ 用户回到已有对话（间隔 > 5 分钟）
→ 由 P0「会话恢复摘要」检测时间间隔并输出前情提要
→ 若用户输入「继续」→ 读取 _index.json → 读取 novel_runtime.json → 输出前情提要 + 选项
→ 若用户未输入「继续」→ 按正常对话流程处理
```

**切换小说**：
```
→ 用户发送「切换小说《XXX》」
→ [步骤1] 读取目标小说的 novel_runtime.json（失败则取消）
→ [步骤2] 写入当前小说状态到 novel_runtime.json（失败则取消）
→ [步骤3] 写入 _index.json：act = 目标小说名（失败则取消）
→ 输出切换确认 + 目标小说前情提要 + 选项
```

> **原子性保证**：步骤 1-3 中任一失败，整个切换操作中止，系统回滚到切换前的状态。

**删除小说**：
```
→ 用户发送「删除小说《XXX》」
→ 二次确认后从 _index.json.nvs[] 移除对应条目
→ 若被删除的是当前激活小说 → act 置 null
```

### 紧急降级

| 失败模式 | 表现 | 兜底 |
|----------|------|------|
| 写入失败（权限/磁盘满） | 状态丢失本轮变化 | **不中断叙事**，降级为纯上下文模式。下次写入自动重试 |
| 读取失败（文件不存在） | 新手或文件丢失 | 降级为当前行为——从对话上下文或持久存档恢复 |
| `novel_runtime.json` 损坏 | 无法恢复运行时状态 | **三重降级**：①加载最近持久存档的状态摘要 → ②从对话上下文缓存恢复 → ③输出警告，按首次启动流程重新开始 |
| `_index.json` 不存在 | 首次使用 | 自动创建 `{"act":null,"nvs":[]}` |
| `_index.json` 损坏 | 小说列表丢失 | 扫描 `{存储根}/` 目录重建索引 |
| 切换小说时步骤 2/3 写入失败 | 切换中断 | 放弃切换，保持当前小说不变 |

### 与现有系统的交互

| 系统 | 交互方式 |
|------|----------|
| **外部 CLI** | 运行时 JSON 为纯文件操作，不依赖任何外部 CLI |
| **持久存档** | 存档后同步更新 `ms` 字段。加载存档时同步覆盖 `novel_runtime.json` |
| **轻量存档/回退栈** | 不动。运行时 JSON 不介入回退逻辑 |
| **里程碑自动存档** | 触发时同步更新 `ms` |
| **场景卡模式** | 进入时备份 `scs_bak`，退出时整体恢复 |
| **导出机制** | `ex` 游标精确追踪已导出字数 |
| **沉浸模式** | 不影响 |
| **非剧情阶段指令边界** | `切换小说`/`小说列表`/`删除小说` 仅全局状态下可用 |
