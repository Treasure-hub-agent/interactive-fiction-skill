# 子Agent 生成模式（P1 按需加载）

> 本章在切换或开启「子Agent 生成模式」时加载。核心约束（P0 恒适用）见 SKILL.md §叙事生成模型规则。

---

## 子Agent 生成模式 = 开（子任务派发）

> 子任务派发依赖宿主环境支持（如 Hermes 的 delegate_task、Claude Code 的 Task）。不支持时自动走「主 Agent 直出」模式，见文末降级说明。

 角色 | 职责 | 模型 | thinking |
------|------|------|:--:|
 主 Agent（当前会话） | 加载 skill 规则 + 组装上下文包 + 派发子任务 + 接收正文 + 追加状态条/选项/提示行 + 输出 | 当前模型 | ON（建议） |
 子 Agent（子任务） | 接收上下文包 + 生成正文叙事 + 返回纯文本 | 默认模型 | **OFF** |

**上下文包必须包含（精简注入，防漂移）**：
- 当前故事状态：仅注入与当前场景相关的字段（章节/场景/好感度/关键事件），避免全量历史堆积
- 本轮相对上轮的**变化摘要（diff）**：仅列出本轮回合新增/变更的事实，供子 Agent 增量衔接
- 一句话主角身份锚点（姓名 · 路线 · 核心动机），每轮固定前置以防人设漂移
- 用户本次输入（选项选择或自由行动）
- 当前生效的模式/路线规则关键摘要
- 当前角色卡/场景卡（如已弹出，仅相关角色的精简字段）
- 最近 3 轮叙事摘要（维持连贯性，超 3 轮的差异已并入 diff）
- 正文字数要求（摘要：500-1200字，例外优先于主区间：快进首段/紧迫轮次可低至250字，随机开局首段可300-800字，叙事越紧张越贴近下限；情势转折点/节点自然收束处结束，禁止一段闭环整个事件；若事件已自然完结可正常收束。详见 SKILL.md §正文格式约束）
- ⚠️ **漂移护栏**：角色名、已确立的关系、已锁定的世界规则等核心 canon 事实不得因精简而省略；若当前场景无关但属 canon 锚点，须保留在身份锚点行或单独标注，确保子 Agent 不凭空改写设定
- ⚠️ **句式多样性约束**（从 P0 继承，必须写入 context）：同一修辞结构在同一段落中出现不超过 1 次（角色对话豁免）
- ⚠️ **头脑风暴/枚举清单禁令**：引导语用一句画面方向，禁用「包含A/B/C/D」式枚举

**子Agent 仅返回纯正文文本**，不包含选项、不包含状态条、不包含指令提示行。主 Agent 收到后追加状态条 + 选项 + 指令提示行。

🔴 **子Agent 写入禁止**：子 Agent 不具备文件写权限——所有文件操作（novel_runtime.json 更新、存档落盘、角色卡写入、narrative_buffer.txt 追加等）**必须由主 Agent 亲自执行**。若子 Agent 在返回正文中声称「已写入/已更新某文件」——此为幻觉，主 Agent 忽略该声明，自行执行实际写入。

**输出合并规则**：子 Agent 返回正文后，主 Agent 按 P0 格式规范组装完整输出。

## 子Agent 生成模式 = 关（默认 · 主Agent直出）

 角色 | 职责 | 模型 | thinking |
------|------|------|:--:|
 主 Agent | 接收用户输入 + 直接生成正文叙事（受 P0 写作约束）+ 追加状态条/选项/提示行 + 输出 | 当前模型 | ON（建议） |

**行为差异**：
- 不派发子任务，主 Agent 直接承担正文写作
- 无需组装上下文包，无需角色卡三件套打包——主 Agent 自身知道当前故事状态和角色设定
- 不受子Agent 特定规则约束（无上下文包规范、无 thinking OFF 要求、无子Agent写入禁止）
- 但仍须遵守：正文格式约束（字数区间、收尾规则）、句式多样性（不超过1次）、视角规则、迷你状态条、选项格式（铁律#0 强制自检清单全部生效）
- 主Agent 直出时 thinking 模式保持 ON（可选，由主Agent自己把握），不需要为节约 token 关闭

**降级说明**：当子Agent 生成模式为「开」但子任务派发连续 2 次不可用时，自动降级为直出，状态条后追加 `[子Agent降级]` 标记（仅一次）。用户可手动关闭子Agent生成模式跳过重试。

## 子Agent 生成模式开关

> 一个运行时标记，控制正文生成模式——子Agent（子任务派发）还是主Agent直出。
> 默认：**关（主Agent直出）**。状态不持久化，每次加载 skill 重置为默认。

 指令 | 效果 | 响应范围 |
------|------|:--------:|
 「切换子Agent生成」/「子Agent模式」 | 开 ↔ 关 切换 | **任意阶段**（剧情运行中、启动页、角色卡短篇内均可） |

**启动页展示规则**：展示启动页时，在 A/B/C/D/E 选项下方增加一行配置状态，格式为：
```
⚙️ 子Agent生成模式：{关/开} ｜ 输入「切换子Agent生成」切换
```
处于剧情中时，若用户未主动查询，不重复展示本行。
