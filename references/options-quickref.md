# 选项格式速查卡

> v10.0.0 · 完整规则以 `SKILL.md` §选项格式 为准。
> 定位（v10.0.0）：选项是**参考指引 + 兜底**，用户自由输入（行为/台词）是等权/优先的推进方式；选项须基于用户最近自由输入后的新局势展开。
> 当前字数区间：A/B/C/D 12-20字，E ≤15字。

## 常见错误
| 错误 | 错误写法 | 正确写法 |
|------|----------|----------|
| D选项超字数 | `D · [主角] 「TA 常年游走于不同城市，暗中观察着各方势力的动向与盘算，并试图从中寻找突破口。」` | `D · [主角] TA 是来求救的，不是来复仇的` |
| 标签错误 | `D · [推理] TA 是来求救的` | `D · [主角] TA 是来求救的` |
| 选项带标点 | `A · [证据] TA 在躲人。` | `A · [证据] TA 在躲人` |
| A/B/C同类型 | A=[进攻] B=[进攻] C=[策略] | A=[进攻] B=[策略] C=[避险] |
| 重大情节后忘选项 | 正文写到动情处直接收尾 | 强制在最后三行检查选项 |

## 选项降级速查
- **触发**：场景仅支撑两个真分支（C 为 A 或 B 的换皮/组合/延续）
- **判定**：若删除 A 后 B 仍是完整可选行为 → 通过；C 独立检查同理
- **降级后**：仅输出 A/B + D/E（合规降级变体），不硬凑五选项。A/B 仍须互斥+独立
- **降级豁免**：降级轮次免 A/B/C 互斥/节奏/独立中对 C 的要求

## dilemma 标记速查
- **触发**：theme ≠ null 且当前为关键转折节点
- **标记**：A/B/C 选项标注 `dilemma = true`，写入 choices[] 的 flag 字段
- **纯爽文**（theme = null）永不触发

## E 选项三级锚点
- 🟢公开 → "快进到{地点}·{时段}"
- 🟡有剧透 → "快进到下一场{事件类型}"
- 🔴全剧透 → "跳过当前时段"
- 关键抉择点禁 E（倾向多禁少放）

## 定情后标签速查（v10.1.0 新增）

> **定位**：v10.0.0 既有 emotion 池覆盖「心动/暧昧/定情」三阶段，**v10.1.0 新增 emotion_daily 池**覆盖「定情后」日常场景。三池互斥，同轮只能选 1 个。

### 触发条件（双锚定）

| 锚点 | 条件 | 备注 |
|------|------|------|
| 1 | `cp{}.stage == "定情"` | 三阶段已完成 |
| 2 | 用户输入命中 keywords（≥1 个） | 15 个关键词见 `data/emotion_daily.json` |

双锚定命中 → emotion_daily 池激活

### 4 档场景与标签

| 场景 | 节奏 | 标签词 | 适用 |
|------|------|--------|------|
| **日常亲密** | 慢 | 陪伴 / 默契 / 依赖 / 琐碎 / 日常 | 自然相处、默契生活 |
| **共同决策** | 迂回 | 商量 / 权衡 / 妥协 / 共识 / 分歧 | 重大选择、相互让步 |
| **冲突** | 快 | 争执 / 冷战 / 失望 / 质疑 / 沉默 | 矛盾爆发、价值观碰撞 |
| **和解** | 慢 | 道歉 / 拥抱 / 释然 / 心疼 / 重新开始 | 关系修复、情感重建 |

### 节奏约束

A/B/C 三选项必须覆盖快/慢/迂回三节奏（4 档场景只有 1 档「冲突」是快，需要 A/B/C 选 3 档不同场景）

**示例**：A=日常亲密（慢）/ B=共同决策（迂回）/ C=冲突（快）—— 三节奏全覆盖

### 触发关键词

```
日常 / 明天 / 未来 / 之后 / 习惯
我们 / 结婚 / 以后 / 永远 / 一起
将来 / 两个人 / 成家 / 过日子 / 余生
```

### 场景结束判定

- 用户主动切换其他场景 OR 输入「切回主线」类指令 → 退出 emotion_daily 池
- 退出后恢复 general 池，不再回退到 emotion 池
- 触发与退出规范详见 `references/intimate-character-voice.md` §定情后语态演变

### 鉴错

- ❌ 「A=陪伴 B=默契 C=依赖」—— 3 个全在「日常亲密」1 档里，**没覆盖三节奏**
- ✅ 「A=陪伴(慢) B=商量(迂回) C=争执(快)」—— 3 档不同场景，三节奏全覆盖
- ❌ 「定情阶段还在用 emotion 池」—— 错。定情完成 → 自动切 emotion_daily 池
- ❌ 「emotion_daily 池里夹带 general 池标签」—— 错。三池互斥，同轮只能 1 个
