# 选项格式速查卡

> v9.3.1 · 完整规则以 `SKILL.md` §选项格式 为准。
> 定位（v9.3.1）：选项是**参考指引 + 兜底**，用户自由输入（行为/台词）是等权/优先的推进方式；选项须基于用户最近自由输入后的新局势展开。
> 当前字数区间：A/B/C 12-20字，D 15-30字，E ≤15字。

## 常见错误
| 错误 | 错误写法 | 正确写法 |
|------|----------|----------|
| D选项超字数 | `D · [主角] 「TA 常年游走于不同城市，暗中观察着各方势力的动向与盘算，并试图从中寻找突破口。」` | `D · [主角] TA 是来求救的，不是来复仇的` |
| 标签错误 | `D · [推理] TA 是来求救的` | `D · [主角] TA 是来求救的` |
| 选项带标点 | `A · [证据] TA 在躲人。` | `A · [证据] TA 在躲人` |
| A/B/C同类型 | A=[进攻] B=[进攻] C=[策略] | A=[进攻] B=[策略] C=[避险] |
| 重大情节后忘选项 | 正文写到动情处直接收尾 | 强制在最后三行检查选项 |

## 选项降级速查
- **触发**：场景仅支撑两个真分支（C 为 A 或 B 的换皮/组合/延续）
- **判定**：若删除 A 后 B 仍是完整可选行为 → 通过；C 独立检查同理
- **降级后**：仅输出 A/B + D/E，不硬凑第三。A/B 仍须互斥+独立
- **降级豁免**：降级轮次免 A/B/C 互斥/节奏/独立中对 C 的要求

## dilemma 标记速查
- **触发**：theme ≠ null 且当前为关键转折节点
- **标记**：A/B/C 选项标注 `dilemma = true`，写入 choices[] 的 flag 字段
- **纯爽文**（theme = null）永不触发

## E 选项三级锚点
- 🟢公开 → "快进到{地点}·{时段}"
- 🟡有剧透 → "快进到下一场{事件类型}"
- 🔴全剧透 → "跳过当前时段"
- 关键抉择点禁 E（倾向多禁少放）

## 标签词汇库

> 权威数据源：`data/tags.json`（本表为人审阅副本）。选词从 `data/tags.json` 读取，A/B/C 互斥 / 节奏约束不变。

| 类型（节奏） | 变体词 |
|------|------|
| 进攻型（快） | 进攻 / 直取 / 强攻 / 摊牌 / 抢攻 |
| 避险型（慢） | 避险 / 退守 / 隐忍 / 拖延 / 回避 |
| 策略型（迂回） | 策略 / 周旋 / 设局 / 借力 / 谈判 |
| 探索型（慢） | 探索 / 调查 / 观察 / 试探 / 摸索 |
| 社交型（迂回） | 社交 / 安抚 / 套话 / 示好 / 周旋 |
| 亲密型（慢） | 亲密 / 暧昧 / 撩拨 / 示弱 / 靠近 |
| 越轨型（快） | 越轨 / 冒险 / 赌注 / 破格 / 孤注一掷 |

> 亲密场景标签池：温柔主导(慢) / 克制回应(慢) / 主动迎合(快) / 被动承受(慢) / 退让收束(迂回)，A/B/C 选自该池仍须覆盖快/慢/迂回三节奏；结合阶段收尾或选 E 后场景结束，恢复普通标签池

## 拓展常见错误
| 错误 | 示例 |
|------|------|
| 选项加推荐语 | ❌ "选 B 最稳妥，推荐" |
