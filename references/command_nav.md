# 命令与导航解析字典（按需加载）

> 说明：「加载小说包·随机」直接随机开局

> **【加载触发】** 当 AI 解析到用户输入为「系统指令」或「导航输入」时加载本文件（参见 `SKILL.md` 铁律 #0 区域的用户输入归属 3 条优先级判定）。纯剧情轮（自由文本融入正文）不需要加载本文件，不占用每轮上下文。本文件是命令查找表与导航规范的**权威字典**，SKILL.md 仅保留分类判定与指针。
>
> **【数据层】** 高频指令快速路由见 `data/commands.json`；本文件为完整指令→效果映射与导航规范的**权威字典**。
>
> **【使用指南】** 用户发送「帮助」「使用指南」，或启动页选择 F 时，加载 `references/usage-guide.md`（面向用户的指令速查文档）。

## 非剧情阶段指令边界

以下四个阶段统称「非剧情阶段」，所有剧情指令（切换模式/切换视角/存档/导出/重新开始/进度/查看存档/当前目标/世界观/关系/人物志/角色卡/场景卡/加载存档/切换路线/切换小说/小说列表/删除小说）在此类阶段中一律无效，AI 需友好提示用户「当前处于{阶段名}，暂不支持该指令」，并引导该阶段可执行的操作。

| 阶段 | 标识 | 可用的操作 |
|------|------|-----------|
| 蒸馏流程中 | 处于角色蒸馏系统（见 `extended/distillation.md`）的 Phase 1-7 任一阶段 | 蒸馏流程内的选项/输入 |
| 角色创建中 | 处于角色创建系统（见 `extended/creation_world.md`）的步骤 0-3，或深度创建流程（见 `extended/deep_character_creation.md`）的任一阶段 | 创建流程内的选项/输入 |
| 开局选择中 | 路线选择 / 开局配置确认 任一环节 | 选择项（A/B/C 等） |
| 角色卡短篇中 | 处于角色卡短篇模式中（`· 角色卡短篇 · {地点} ·`） | 短篇内的选项/输入、「导出小说」、切换人称/视角（同正文）、选卡阶段支持「查看{作品名}的角色卡」筛选 |

跨路线指令（如非创世路线中发送「加载创世路线存档」）提示「当前路线不支持此指令，请先切换路线」。

## 菜单导航指令规范（全局）

> AI 虽能靠语义识别「上一步」「返回主菜单」等意图，但以下规范可让响应更快、行为更可预期。所有非剧情菜单、多级流程均适用。

| 指令 | 行为 | 速度要求 |
|------|------|:--:|
| 「上一步」/「返回上一步」/「退一步」/「上一步骤」 | 在当前多级流程中回退一级：角色创建步骤 0-3、深度创建四轮问答、创世七维、角色卡短篇选卡（步骤1/2→步骤0）、蒸馏 Phase 等 | **直接重建上一级界面**，不重复解释背景、不道歉 |
| 「返回主菜单」/「主菜单」/「启动页」/「菜单」/「首页」 | 立即退出当前所有子流程（含任意层级菜单、角色创建、蒸馏、深度创建、角色卡短篇），回到一级启动页 | **一步直达启动页**，不逐级回退 |
| 「取消」/「算了」/「不做了」 | 中止当前非剧情流程，回到进入该流程前的界面 | 直接退出，不追问（除非涉及删除等不可逆操作） |

**约束**：
- 导航指令**优先于**同阶段的自由文本解析——若用户输入同时像导航词又像剧情行动，按导航处理。
- 处于剧情正文中时，「返回主菜单」提示「当前在剧情中，可先『存档』或『退出沉浸』再返回」；不强行打断叙事。
- 角色卡短篇中发「返回主菜单」= 放弃当前短篇，回启动页（等同选 E 结束）。

## 用户输入归属 · 角色创建阶段例外

> **角色创建阶段例外**：处于角色创建中（`extended/creation_world.md` 步骤 0-3）时，若用户输入为自然语言角色描述且非 A~G 选项，自动路由到 `extended/deep_character_creation.md` 简化模式处理，而非要求手动填全维度。

## 上下文命令提示模板

每轮选项后按场景类型从以下模板池选取：

| 场景 | 模板 |
|------|------|
| 交互后 | `💡 可用：关系 / 存档 / 进度 ｜ 荐：查看配角动态` |
| 战斗/冲突 | `💡 可用：进度 / 存档 / 关系 ｜ 荐：世界观` |
| 通用 | `💡 可用：存档 / 进度 / 关系 ｜ 荐：人物志` |
| 非剧情阶段 | 仅提示该阶段可执行的操作 |

约束：提示行不计入小说导出；每轮仅一行。

> 用户输入归属的 3 条优先级判定（指令 / 选项 / 自由行动）见 `SKILL.md` §用户输入归属规则（每轮必守，P0 常驻）。自由行动按「自由输入即事件」处理：行为/台词直接成为当前帧事件，AI 展开叙事，选项基于其后新局势生成。
