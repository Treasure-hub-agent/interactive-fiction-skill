# 附录：角色外貌创作指南

> **示例说明**：本章各节提供的描写示例仅为风格示意，AI 生成时应基于当前角色气质与场景重新创作，禁止直接照搬示例原文。

---

## §A.0 描写分区（🟢🟡🔴）

> 描写分寸指引：按分区控制外貌描写的细致程度。

| 分区 | 🟢 可细写 | 🟡 适度提及 | 🔴 仅亲密展开 |
|------|-----------|-------------|---------------|
| 默认 | 无限制 | 一笔带过，不展开细节 | 仅亲密场景解锁 |

**🟢🟡🔴 分区规则的适用范围（关键区分）**

以下两种场景适用不同的描写规则：

| 场景 | 适用规则 |
|------|----------|
| **正文生成（叙事描写）** | 遵循 §A.1 三区分级 |
| **亲密场景渐进推进（试探→深入→结合）** | **不适用三区分级**。阶段划分、篇幅和必须涵盖内容由 `extended/features.md` §渐进推进 独立控制 |
| **角色卡创建 / 蒸馏流程 / 角色设定填写** | **不适用三区分级**。AI 基于搜索素材或设定文本，如实、全面描写角色外貌与身材——脸型、五官、身形、肩颈、腰肢、胸部、臀部、腿线、体香、肤质、着装材质与剪裁等所有维度均可详写。**禁止在蒸馏产出中使用"适度提及""一笔带过""不展开""🟡""🟢""🔴"等分区术语或自限短语**——这些术语对蒸馏场景无意义。

**描写分区适用对象**：🟡/🔴 区的适用对象由主角/亲密对象的性别与用户偏好决定，不按性别一刀切。亲密对象按角色卡性别适用 🟡/🔴 区；非亲密对象角色默认仅 🟢 区描写。

## §A.1 外貌描写总则

### 描写时机

| 时机 | 触发条件 | 描写深度 |
|------|----------|----------|
| **首次登场** | 新角色初次出现于叙事中 | 全维度覆盖（面部+身形+着装+气质），按登场六步模板执行 |
| **日常再提及** | 已登场角色的后续出场场景 | 仅强化1-2个外貌记忆点，不重复完整描写 |
| **亲密场景** | 进入亲密场景时 | 启用🔴区域，按亲密场景描写规范执行 |

### 模式差异速查

| 模式 | 外貌描写策略 |
|------|-------------|
| **爽文模式** | 详细展开，每维度可多加1句。🟢区全覆盖，🟡区适量展开，🔴区待亲密场景解锁 |
| **主线模式** | 精简克制，每维度短语级。仅🟢区描写，🟡区略过，🔴区不动 |
| **场景卡** | 同爽文模式，亲密场景启用🔴区 |
| **亲密展开时** | 🔴区全面启用，按亲密场景描写规范执行 |

### 描写密度分区表

| 分区 | 区域内容 | 适用场景 | 描写约束 |
|------|----------|----------|----------|
| 🟢 **可细写** | 整体身形轮廓、头发质感/颜色/发型、腿部线条、肩颈锁骨、腰肢、着装风格、面部（眼/眉/鼻/唇/脸型）、嗓音特征、特殊标记 | 所有场景均可描写 | 无限制 |
| 🟡 **适度提及** | 胸部轮廓、臀部曲线、体香/香水气味、肤质光泽 | 爽文模式可写，主线模式略过 | 不展开细节，一笔带过 |
| 🔴 **仅亲密展开** | 贴身部位细节、肌肤触感详写 | 仅限亲密场景 | 按亲密场景描写规范执行 |

## §A.2 面部描写系统

> **性别适配**：面部/发型/唇形等词库为两性角色共用参考，使用时按角色卡性别选取——男性角色优先硬朗线条类词汇（剑眉/平直眉/丹凤眼/方颌/薄唇/短发/高马尾等），女性角色优先柔和精致类词汇（柳叶眉/弯月眉/桃花眼/樱桃小口/长发/卷发等），避免跨性别误用导致形象错位。

### A.2.1 脸型

| 类别 | 关键气质 | 一句话规则 |
|------|----------|-----------|
| 鹅蛋脸 | 温婉古典 | 线条柔和流畅，额头到下巴一气呵成 |
| 瓜子脸 | 精致灵动 | 下巴尖而不锐，颧骨处微收 |
| 圆脸 | 可爱亲和 | 脸颊饱满，线条圆润 |
| 方脸 | 英气坚毅 | 下颌角分明，轮廓硬朗 |
| 菱形脸 | 冷艳高级 | 颧骨突出，额下巴收窄 |
| 心形脸 | 甜美妩媚 | 额头饱满，下巴尖俏 |

> 用轮廓线条替代术语标签，使描写更自然。

### A.2.2 眉眼

| 类别 | 关键气质 | 一句话规则 |
|------|----------|-----------|
| 柳叶眉 | 温婉 | 远山形弯而自然 |
| 剑眉 | 英气 | 眉尾上扬如剑刃 |
| 平直眉 | 冷静 | 平直无明显弧度 |
| 弯月眉 | 妩媚 | 弯如新月带笑意 |
| 杏眼 | 清纯 | 眼形圆润，黑白分明 |
| 丹凤眼 | 妩媚凌厉 | 眼尾上挑，眼形细长 |
| 桃花眼 | 含情 | 眼周微红，眼尾略弯 |
| 圆眼 | 天真直率 | 眼珠大而圆 |

> 不应单写眼型，应写"眼睛在做什么"——目光的锐利、睫毛的阴影。

### A.2.3 鼻与唇

**鼻**：鼻梁高低、鼻尖形状（小巧/圆润/微翘/鹰钩），以侧面轮廓描写为主。

| 唇形 | 气质 | 规则 |
|------|------|------|
| 薄唇 | 理性冷淡 | 唇线分明 |
| 丰唇 | 性感热情 | 下唇饱满微外翻 |
| 樱桃小口 | 古典娇俏 | 唇珠明显，嘴角上扬 |
| M唇 | 精致傲娇 | 上唇呈明显M形 |

> 唇部描写必须与当前表情绑定，禁止孤立描写。

### A.2.4 肤色与肤质

| 色调 | 质感词库 | 光源互动 |
|------|----------|----------|
| 白皙 | 瓷白、牛奶白、透亮 | 阳光下近乎透明 |
| 小麦色 | 蜜色、古铜 | 汗珠在深色皮肤上晶莹 |
| 粉白 | 白里透红 | 运动后更显红润 |
| 象牙白 | 温润有厚度 | 室内光下最显质感 |

**肤质**：光滑/粗糙、紧致/松弛、特殊质感（绒毛/血管/薄茧）。

### A.2.5 年龄面容差异

| 年龄段 | 核心特征 | 描写重点 |
|--------|---------|----------|
| 青年（18-25） | 线条柔和，胶原饱满，眼神清亮 | 青春感——富有活力 |
| 成熟期（25-35） | 棱角初显，眼角有细纹雏形 | 风情与韵味——从容与故事感 |
| 年长（40+） | 轮廓更清晰，皱纹显现 | 气场与历练——皱纹是故事的痕迹 |

> 避免直接使用"老"字作为外貌标签，优先通过具体细节呈现年龄感。

## §A.3 发型与发饰

### 发型分类

| 大类 | 子类 | 气质 | 描写切入点 |
|------|------|------|-----------|
| 长发 | 直发 | 清纯端庄 | 发丝垂落如瀑，风过时发梢轻扬 |
| | 卷发/波浪 | 妩媚成熟 | 卷曲弧度，弹跳晃动，缠指缠绵 |
| 短发 | 齐耳 | 干练飒爽 | 发尾利落切面，露出后颈清爽 |
| | 波波头 | 时尚俏皮 | 发尾内扣弧度 |
| 马尾 | 高马尾 | 活力飒爽 | 甩动节奏，发绳细节 |
| | 低马尾 | 温婉知性 | 松散碎发，后颈与发丝对比 |
| 盘发 | 发髻 | 端庄贵气 | 高度与松紧，簪子材质 |
| | 编发 | 精致古典 | 发辫纹理走向，花饰丝带 |
| 特殊 | 双马尾 | 俏皮反差 | 活泼感 |

**发色与光泽**：黑发→日光下泛蓝光；棕发→琥珀透亮；金发→融金倾泻；银/白发→月光银丝。发质通过光泽间接体现。

**发饰与身份关联**：玉簪/金钗→贵族端庄；丝带/蝴蝶结→青春甜美；发箍→都市利落；无发饰→战斗随性；花饰→精灵自然。

## §A.4 声音与气味

| 嗓音类型 | 特征 | 适用角色 |
|----------|------|----------|
| 清亮 | 穿透力强 | 青年、活泼型 |
| 沙哑 | 颗粒感烟嗓 | 成熟型、江湖 |
| 甜腻 | 糯软奶音 | 可爱型、治愈系 |
| 低沉 | 磁性浑厚 | 领导者、权威型 |
| 温柔 | 绵软缓慢 | 治愈系、温和型 |

**声音动态**：喘息（紧张/运动/亲密）、颤抖（愤怒/恐惧/感动）、拉长尾音（撒娇）、语速突变（情绪波动）。

| 气味来源 | 类型 | 描写时机 |
|----------|------|----------|
| 体香 | 奶香/花木/皂香 | 近距离接触时 |
| 香水 | 花香/木质/果香 | 登场或经过时 |
| 环境附着 | 油烟/墨香/药草 | 刚出特定环境 |
| 身份气味 | 硝烟/消毒水/花香 | 职业绑定标签 |

> 重要角色首次登场至少一项气味。

## §A.5 特殊标记

特殊标记是角色的专属外貌记忆点。每个标记应有合理的背景故事来源（已揭示/待揭示/纯装饰三档）。

| 类别 | 适用角色 | 示例 |
|------|----------|------|
| 伤痕 | 战斗系 | 眼角细疤、虎口剑茧 |
| 痣/胎记 | 所有角色 | 泪痣、美人痣 |
| 饰品 | 背景绑定 | 不离身的项链、红绳 |
| 纹身/烙印 | 奇幻/江湖 | 符文刺青、组织烙印 |
| 身体特征 | 所有角色 | 异色瞳、虎牙、酒窝 |
| 动作习惯 | 日常强化 | 紧张摸耳垂、思考转笔 |

**重复描写时机**：首次登场 → 角色做相关动作时 → 其他角色注意到时 → 亲密场景中 → 标记相关剧情触发时。

## §A.6 着装系统

**身份匹配**：贵族→丝绸锦缎深色系；江湖战士→粗布皮革耐脏色；职场→剪裁精良 ≤3色；学生→棉麻针织浅色系；仙侠→飘逸门徽色系；市井→粗布麻衣原色。

**场合联动**：战斗→紧身束袖，材质耐磨；正式→礼服正装配饰完整；日常→便服舒适；居家→宽松家居服；潜入→深色无声。场合切换时用过渡句完成换装。

**心境联动**：低落→宽松深色遮蔽身体；自信→剪裁利落色彩明快；勾引→适当暴露面料贴身；防御→多层包裹深色素颜；愤怒→束发紧身褪去累赘。不直接写情绪，通过着装间接呈现。

**材质与触感**：丝绸→滑如水流，窸窣细密；棉麻→微粗糙透气有温度；皮革→挺括有型微嘎吱；纱→轻若无物；呢料→温暖厚实有弹力。

## §A.7 外貌演变

**受伤沉淀**：轻伤→3-5日消，不留痕；中度→刀伤1-2周恢复留浅疤；重伤→月余恢复明显疤痕+后遗症；致命伤→永久性外貌改变。

> 受伤当日必须提及，恢复期每2-3次提醒，痊愈后疤痕作为固定标记。

**气质蜕变映射**：天真→成熟（眼神多审慎，笑容收敛）；弱势→强势（肩背挺拔，下颌微扬）；开朗→阴郁（黑眼圈，嘴角下垂，颜色转深）；世俗→超脱（目光穿透，节奏变慢）。每次蜕变须有对应大事件，3-5次场景逐步过渡。

**主动换装触发**：潜入→对镜自照的心理活动；重要社交→通过他人反应衬托冲击力；分手→剪发作为象征；身份转换→镜中映出陌生自己。

**年龄推进**：1-3年→发型/着装微调；3-5年→面部线条更清晰，身形可能变化；5-10年→全面更新面容+身形+着装+气质；10年+→代际感重建所有维度。

## §A.8 角色外貌简版框架（非亲密对象适用）

**登场四步**：①整体气质（沉稳/张扬/冷峻）→②面部（脸型+眉眼神态+辨识特征）→③身形（身高+体型）→④着装（风格+身份关联）。**默认仅 🟢 区描写**；若该角色为亲密对象且用户偏好，可按完整描写规范升级。

**差异化标签**（选1-2个）：身材特征（高出旁人一头）、面部特征（左眉旧疤）、着装标志（从不摘的旧机械表）、动作习惯（站立重心偏右）。

**非亲密对象角色**：默认不启用 🟡/🔴 区域描写，不使用暧昧语言描写其身体。

## §A.9 登场描写模板（完整版）

新角色首次登场时按以下六步展开：

1. **环境切入**（1句）——TA 出现的地点、时间、光线、天气/氛围。建立空间锚点。
2. **整体气质**（1句）——第一印象（清冷/张扬/慵懒）。定下气场基调。
3. **面部**（2-3句）——从最突出的面部特征开始，五官递进而非罗列。建立视觉辨识度。
4. **身材轮廓**（1-2句）——身高、身形、最突出的身体标签。从动作中自然流露。
5. **着装与关键细节**（1-2句）——服装风格+身份关联+一个值得注意的细节。锚定身份与处境。
6. **动作/姿态收束**（1句）——一个标志性动作或姿态作为落点。浓缩角色状态。

**爽文**：每步多加1句，步骤4追加身体记忆点，步骤5追加材质与肌肤互动。**主线**：压缩为三段自然叙事，字数约爽文1/2。

## §A.10 反差感塑造原则

利用职业/身份/性格与身体特征之间的矛盾制造张力。

**身份反差**：干练型职业与外表特征形成反差；柔弱型身份拥有不符身份的痕迹（如握武器的茧子）。在日常动作中自然显露。

**性格反差**：傲娇/高冷型亲密中暴露敏感羞涩；温柔/弱气型关键时刻爆发力量；话痨型独处时暴露沉默疲惫。先建立性格基线，反差场景中用同一套词汇呈现相反结果。

**场合反差**：战斗训练中紧身服勾勒身形但专注敌人；正式场合中礼服暴露但不自觉。核心是"读者视角中只有我注意到"的独占感。

**自创/创世模式必检清单**：每个推荐角色必须至少拥有一项反差；反差必须有叙事潜力（非纯视觉）；一个角色最多2项反差；反差与世界观兼容。
