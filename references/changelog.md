# 更新日志

## v9.3.1（2026-08-07）· 自由输入优先 + 记忆核对

- **自由输入优先**：选项机制「参考指引」化——用户自由输入（行为/台词）成为等权/优先的剧情推进方式；选项保留 A/B/C/D/E 形式与每轮必跟，但必须基于用户最近自由输入后的新局势展开
- **自由输入即事件**：行为/台词直接成为当前帧事件，AI 展开叙事；禁止旁白化/解释化/归错角色；台词后选项须承接台词打开的新局面
- **记忆核对三查**：强制自检清单新增设定核对（每轮）、后果核对（每轮，`choices[]` `surface_by` 到期必回收）、回响核对（事件触发：场景切换/时间跳跃/关键角色回归/新章节）
- **`choices[]` 升级**：不新增 `open_loops`，复用升级现有 `choices[]`——`type` 枚举扩展（consequence/foreshadow/promise，兼容旧值）、`surface_by` 回收语义、回收纪律（到期正面呈现、open 上限 5-8 条、拖延超 3 轮状态条轻提示）；`novel_runtime.json` 结构兼容，旧存档无缝可用
- **文档同步**：command_nav / usage-guide / options-quickref / storage_runtime 同步；MANIFEST.json 重新生成全部 SHA256

## v9.3.0（2026-08-04）· 性别通用化 + 结构简化

- **性别通用化**：视角规则、角色命名、描写规范、示例全部中性化——亲密对象用「他/她」（按角色卡性别），示例用 TA/示例角色，随机开局性别改为男/女等权随机，删除「女主/女角/女方/后宫」等性别偏向表述
- **结构简化**：移除「隐藏模式」开关与亲密场景门控流程，描写分区与渐进推进改为自然适用的规范指引
- **描写规范精简**：渐进推进保留三阶段框架（试探→深入→结合），大幅简化具体描写法；亲密场景描写规范压缩为克制指引
- **发布前一致性修复**：角色卡短篇界面代词中性化；E 选项字数统一为 ≤15 字；存档/世界观落盘路径统一至 `{存储根}` 规范；句式多样性统一为同段内 ≤1 次；随机开局字数例外与状态条同步 P0；登场模板统一为六步；示例代词统一为 TA；token 数值弱化
- **新增使用指南**：`references/usage-guide.md` 外置轻量文档，按功能域列举全部用户可用指令（含子Agent 生成模式等隐藏功能）；启动页 F「帮助」与「帮助/使用指南」指令接入
- **双用户实测后澄清**：新增指令轮状态条降级与指令轮正文衔接规范（含存档轮）；字数例外优先级明确（例外优先于主区间）；主线模式渐进推进降级为试探→深入、结合阶段含蓄收束；创世步骤3 顺序澄清（统一走配角创建流程）；亲密标签池补节奏标注与场景结束判定；世界观引入改为 1-2 句轻量引入（不省略）；外观词库补性别适配指引
- **流程修正**：角色创建完成后的流转选项交换——**A=跳过**（不创建配角，直接进入下一步）、**B=创建配角**（原 A/B 语义相反），消除"默认继续创建配角"的诱导；`deep_character_creation.md` 深度创建路径同步
- **角色创建简化**：移除独立的「初始亲密角色创建」步骤——亲密对象并入配角创建（用户通过 B 创建配角时在角色卡「人际关系」标注关系即可），`creation_world.md` §三 改为亲密对象描写规范
