# 使用指南（用户指令速查）

> 轻量外置文档：启动页选「F. ❓ 帮助」或发送「帮助」「使用指南」时加载。本节按功能域列出全部用户可用指令，方便随时查阅。完整导航规则见 `references/command_nav.md`。

## 一、激活与开局

| 指令 | 效果 |
|------|------|
| 「加载小说包」 / 「加载互动小说技能包」 | 弹出启动页与路线选择 |
| 「加载小说包·穿越」 | 直接进入穿越成原著角色路线 |
| 「加载小说包·自创」 | 直接进入自创角色路线 |
| 「加载小说包·创世」 | 直接进入创世模式 |
| 「加载小说包·随机」 | 随机骰决定路线+模式+世界观基调，可换可改一键开局 |
| 「继续上次」 / 「继续上次进度」 | 加载最近一次存档，直接进入正文 |

## 二、模式与视角

| 指令 | 效果 |
|------|------|
| 「切换爽文模式」 | 切换到爽文模式（剧情爽点驱动） |
| 「切换主线模式」 | 切换到主线模式（精简克制） |
| 「切换第一人称」 / 「切换第二人称」 / 「切换第三人称」 | 切换叙事视角 |

## 三、子 Agent 生成模式（隐藏功能）

| 指令 | 效果 |
|------|------|
| 「切换子Agent生成」 / 「子Agent模式」 | 切换正文生成模式：**子Agent派发 ↔ 主Agent直出**。默认「关」（主Agent直出，即当前会话 AI 直接写作） |
| — 开关 = 开 | 正文由独立子Agent生成（依赖宿主环境支持，如 Hermes 的 delegate_task / Claude Code 的 Task），主Agent 组装上下文并追加选项 |
| — 开关 = 关（默认） | 主Agent 直接承担正文写作，无需额外配置 |

> 💡 说明：默认主Agent直出，绝大多数用户无需开启子Agent模式。开启后正文由子Agent生成、质量更高，但需要宿主环境支持子任务派发；不支持时会自动降级回主Agent直出。

## 四、存档与进度

|------|------|

| 「加载存档 #N」 | 加载编号 N 的存档（N 为存档编号） |
| 「删除存档 #N」 | 删除编号 N 的存档（二次确认） |
| 「批量管理存档」 | 批量管理存档（删除 / 导出 / 对比） |
| 「加载XX路线存档」 | 加载对应路线的最新存档 |
| 「进度」 | 查看剧情进度仪表盘 |
| 「转为正常路线」 | 随机开局的小说转正为正常路线（保留存档与进度，存档编号不重置） |
| 「导出随里程碑 开」 / 「导出随里程碑 关」 | 开启 / 关闭里程碑自动导出（每次里程碑自动存档时同步追加导出，默认关） |
| 「重新开始」 | 归零重新开始 |

## 剧情中的自由输入

> v9.3.1 起：**自由输入优先**——直接输入行为/台词是推进剧情的主要方式（与选 A/B/C/D/E 等权），选项是参考指引 + 兜底，会基于你最近的自由输入自动衔接展开。

除上述指令外，剧情推进期间所有自由文本都作为**主角的言行**融入正文：

- **选择选项**：输入 A/B/C/D/E（可附带微调，如「B，但先不要正面回答」）
- **自由行动**：直接描述想做的事（如「我掏出武器逼问对方」）
- **角色台词**：输入带引号的对话（如「我记得你说过……」），AI 会让对应角色自然说出，并承接这句话展开新局面

> ⚠️ 若想在剧情中说一句与指令同名的台词（如角色大喊「存档！」），在输入前加 `>` 前缀强制作为台词处理。
