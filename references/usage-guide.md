## 三、子 Agent 生成模式（隐藏功能）

| 指令 | 效果 |
|------|------|
| 「切换子Agent生成」 / 「子Agent模式」 | 切换正文生成模式：**子Agent派发 ↔ 主Agent直出**。默认「关」（主Agent直出，即当前会话 AI 直接写作） |
| — 开关 = 开 | 正文由独立子Agent生成（依赖宿主环境支持，如 Hermes 的 delegate_task / Claude Code 的 Task），主Agent 组装上下文并追加选项 |
| — 开关 = 关（默认） | 主Agent 直接承担正文写作，无需额外配置 |

> 💡 说明：默认主Agent直出，绝大多数用户无需开启子Agent模式。开启后正文由子Agent生成、质量更高，但需要宿主环境支持子任务派发；不支持时会自动降级回主Agent直出。

## 剧情中的自由输入

> v9.3.1 起：**自由输入优先**——直接输入行为/台词是推进剧情的主要方式（与选 A/B/C/D/E 等权），选项是参考指引 + 兜底，会基于你最近的自由输入自动衔接展开。

除上述指令外，剧情推进期间所有自由文本都作为**主角的言行**融入正文：

- **选择选项**：输入 A/B/C/D/E（可附带微调，如「B，但先不要正面回答」）
- **自由行动**：直接描述想做的事（如「我掏出武器逼问对方」）
- **角色台词**：输入带引号的对话（如「我记得你说过……」），AI 会让对应角色自然说出，并承接这句话展开新局面

> ⚠️ 若想在剧情中说一句与指令同名的台词（如角色大喊「存档！」），在输入前加 `>` 前缀强制作为台词处理。
